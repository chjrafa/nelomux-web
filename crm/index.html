Conecta el CRM

Falta conectar la base de datos. Son 5 minutos, una sola vez:

  1. Crea un proyecto gratis en supabase.com.
  2. En SQL Editor, pega y corre el archivo crm/supabase.sql.
  3. En Authentication → Users, crea tu usuario con correo y contraseña.
  4. Copia Project URL y la anon public key (Project Settings → API) en config.js.
